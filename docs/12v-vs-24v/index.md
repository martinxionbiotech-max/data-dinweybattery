# 12V vs 24V Truck Electrical Systems

**TL;DR** — Light trucks and pickups use 12V electrical systems; heavy trucks, semi trailers
and buses use 24V systems built from two 12V batteries wired in series.

## Why Two Voltages?

- **12V** — standard for light vehicles and light/medium trucks. Simpler, lower cost.
- **24V** — used by heavy trucks and buses because it halves the current for the same power,
  allowing thinner wiring and more reliable cranking of large diesel engines.

## How a 24V System Works

A 24V system is typically built from **two 12V batteries connected in series**:

```
Battery 1 (+) ──→ Battery 2 (−) ──→ 24V output
        (+) of battery 1 and (−) of battery 2 form the 24V terminals
```

In series, voltages add (12V + 12V = 24V) while the current stays the same.

| Configuration | Voltage | Current | Typical use |
|---|---|---|---|
| Single 12V | 12V | Higher current | Light trucks, pickups |
| Two 12V in series | 24V | Halved current | Heavy trucks, buses |
| Two 12V in parallel | 12V | Doubled capacity | Extended runtime |

## Common Mistakes

- **Replacing only one battery** of a 24V pair — always replace both as a matched pair for
  balanced charging.
- **Wiring in parallel when 24V is needed** — parallel doubles capacity but stays 12V.
